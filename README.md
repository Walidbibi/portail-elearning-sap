# Portail SAP du DP

Site de révision pour comprendre et piloter un programme SAP (ECC vers S/4HANA) : parcours conseillé, frises interactives (roll-out, greenfield, brownfield, bluefield), supports en PDF lisibles page par page et glossaire de 136 termes.

Contenu générique : les entreprises, sites et chiffres des exemples sont fictifs.

## Consulter en local

```bash
python3 -m http.server 8080
```

Puis ouvrir http://localhost:8080.

## Mettre à jour un document

Remplacer le PDF dans `documents/` par un fichier du même nom. Le site se met à jour au prochain déploiement.
